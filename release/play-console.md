## 1. ストア掲載情報

### アプリ名（30文字以内）

```
小役カウンター
```

### 短い説明（80文字以内）

```
スロットの小役回数を数えるカウンター。ボタンは最大9個。片手で押しやすく、数えた内容は自動で保存されます。
```

### 詳しい説明（4000文字以内）

```
スロットの小役回数を数えるためのカウンターアプリです。
余計な機能は入れず、「押しやすさ」と「見やすさ」だけを考えて作りました。

■ 基本の使い方

・画面下のボタンを押すと、その回数が1つ増えます
・上部の大きい数字が現在のゲーム数、その下に合計が出ます
・開始ゲーム数を入力しておくと、そこからの差分を数えられます
・押し間違えたときは、ボタンを長押しすればその場で回数を直せます
・数えた内容は自動で保存されるので、アプリを閉じても続きから使えます

■ ゲーム数の自動カウント

再生ボタンを押すと、4.1秒ごとに自動でゲーム数が進みます。
停止ボタンでいつでも止められます。

■ 画面は使いやすいように変えられます

・下部のボタンは1個から9個まで、必要な数だけ表示できます
・「シンプル表示」に切り替えると、開始ゲーム数・合計・再生／停止などを隠して、
　カウントだけに集中できる画面になります

■ プレミアム（買い切り／月額）

より自分好みに使いたい方向けに、有料のプレミアム機能を用意しています。

・ボタンを自由な位置・サイズに配置できる
・ボタンの色やグラデーションを自由にカスタマイズ
・お好きな画像や配色で背景を変更できる
・メモ帳ウィジェットを画面に追加できる
・経過秒数（0.000〜4.100）表示の濃さを調整できる
・ボタンごとに設定1〜6の小役確率をメモできる
・ボタンに「ベル」「チェリー」など名前を付けられる
・レイアウトを名前を付けて保存し、すぐ呼び出せる

買い切りプランと月額プランのどちらかを選べます。
月額プランの解約は、Google Play のサブスクリプション管理からいつでも行えます。

■ その他

・広告は表示しません
・アカウント登録は不要です
・数えた内容や設定は端末内にのみ保存され、外部に送信されることはありません

プライバシーポリシー：
https://gauruga.github.io/katikati/privacy.html
```

## 2. データセーフティ申告

「収集」＝端末の外へ送信すること、という Play の定義に沿って回答する。
本アプリは開発者自身のサーバーを持たないが、RevenueCat 経由で課金情報が送信されるため
「収集しない」とは答えられない点に注意。

### 収集するもの

| データの種類 | 収集 | 目的 | ユーザーに紐づくか | 必須か |
| --- | --- | --- | --- | --- |
| 購入履歴（金融情報 > 購入履歴） | はい | アプリの機能 | はい | 必須 |
| デバイスまたはその他の ID | はい | アプリの機能 | はい | 必須 |

- 購入履歴：購入した商品・購入日時・契約の有効期限・解約や返金の状態。
- デバイスまたはその他の ID：RevenueCat が自動発行する匿名の利用者識別子。
  広告 ID は収集していない（`collectDeviceIdentifiers()` を呼んでいないため）。

### 収集しないもの（明示的に「いいえ」と答える）

- 氏名・メールアドレス・電話番号・住所などの個人情報
- 位置情報
- 写真や動画 … 背景画像は端末内でのみ使用し、送信しない
- アプリのアクティビティ、アプリ内検索、閲覧履歴
- 連絡先、カレンダー、SMS、通話履歴
- クラッシュログ・診断情報 … 解析ツールを組み込んでいないため

### セキュリティに関する質問

| 質問 | 回答 |
| --- | --- |
| データは転送中に暗号化されますか | **はい**（RevenueCat / Google Play とも HTTPS） |
| ユーザーはデータの削除をリクエストできますか | **はい**（問い合わせ先メールで受け付ける） |

### 「共有」の扱い（要確認）

Play の定義では、開発者の代わりに処理を行うサービスプロバイダへの転送は
「第三者との共有」に該当しないと整理できる。RevenueCat はこれに当たると考えられるため、
共有は「いいえ」で回答する想定。
ただし RevenueCat が公式にデータセーフティの記入ガイドを出しているので、
提出前に最新版を確認して食い違いがないか照合すること。

## 3. コンテンツレーティング質問票

IARC の質問票に回答する。**カテゴリは「ゲーム」ではなく「参考、ニュース、または教育」系のアプリ**を選ぶ
（本アプリはゲームではなくカウンターツールのため）。

想定される主な回答：

| 質問の趣旨 | 回答 |
| --- | --- |
| 暴力表現 | なし |
| 性的表現 | なし |
| 不適切な言葉 | なし |
| 薬物・アルコール・たばこ | なし |
| 現実の金銭を賭ける機能があるか | **いいえ** |
| ギャンブルをシミュレートする内容か | **いいえ**（回数を数えるだけで、遊技そのものは含まない） |
| ユーザー間の交流機能 | なし |
| 位置情報の共有 | なし |
| 個人情報の共有 | なし |

本アプリは実際に金銭を賭ける機能を持たず、遊技そのものを再現するものでもないため、
Play の「ギャンブル、ゲーム、コンテスト」ポリシーの対象外という整理になる。
ただし用途がスロットに関するものであることは事実なので、質問には正直に答えること。

## 4. 画像素材（未着手）

| 素材 | 要件 | 状態 |
| --- | --- | --- |
| アプリアイコン | 512 × 512 px, 32bit PNG | 既存アイコンから書き出す |
| フィーチャーグラフィック | 1024 × 500 px | **未作成** |
| スマートフォンのスクリーンショット | 最低2枚（推奨4〜8枚）、9:16、各辺 320〜3840px | **4枚撮影済み**（`release/screenshots/`、1080×1920） |
| タブレットのスクリーンショット | 任意。無いとタブレット向けの露出が減る | 後回しで可 |

要件は Play Console 側で随時変わるため、アップロード時の検証メッセージを正とすること。

撮影済みのスクリーンショット（すべて 1080×1920 / 9:16）:

| ファイル | 内容 |
| --- | --- |
| `01-simple.png` | シンプル表示。ボタン9個を大きく使える状態 |
| `02-counter.png` | 通常表示。開始ゲーム数・合計・再生／停止まで入った画面 |
| `03-layout.png` | レイアウト変更（ボタン数の切り替え） |
| `04-menu.png` | メニュー。プレミアム項目とプライバシーポリシーの導線 |

撮影方法（再撮影が必要になったとき）:

```sh
emulator -avd Pixel_9a &
adb shell wm size 1080x1920 && adb shell wm density 420   # 9:16 に固定して撮る
flutter build apk --debug --target-platform android-x64
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb exec-out screencap -p > shot.png
adb shell wm size reset && adb shell wm density reset      # 後片付け
```

エミュレータの既定は 1080×2424（1:2.24）で、9:16 に収まらない。
`wm size` で固定してから撮ると、Play の比率要件を確実に満たせる。

背景変更やレイアウト保存などプレミアム機能の画面は、RevenueCat の設定が済んで
実際に課金状態にできてから撮り足す。

## 5. 書くときの注意

1. **機種名や商標を書かない。** 特定のパチスロ機の名称やランプの通称は各メーカーの商標。
   ストア掲載文にもスクリーンショットにも入れないこと。
   （`lib/gogo_lamp_button.dart` のソースコメントに機種名が出てくるが、
   画面に表示される文言ではないので掲載物には影響しない）
2. **「勝てる」「攻略」「必勝」「期待値」といった表現を使わない。**
   誇大表現と受け取られるほか、ギャンブル関連ポリシーの審査を無用に厳しくする。
3. **スクリーンショットに実在のホール名や個人情報が写り込まないようにする。**
4. 説明文に書いた機能は、無料で使えるのかプレミアムなのかを取り違えないこと。
   上記の下書きでは、自由配置・色変更・背景・メモ帳・秒数の濃さ・確率メモ・ボタン名・
   レイアウト保存の8つがプレミアムで、それ以外は無料。
